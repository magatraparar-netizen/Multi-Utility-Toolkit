
# Multi-Utility Toolkit

## Project 7: Modular & Packager

### Description
This is a Python project that demonstrates modules,
packages, functions, and built-in libraries.

### Features
1. Date and Time Operations
2. Mathematical Operations
3. Random Number and List Generation
4. Random Password and OTP Generation
5. UUID Generation
6. File Read and Write Operations
7. Custom Mathematical Functions
8. Module Attribute Exploration using dir()

### Python Modules Used
- datetime
- time
- math
- random
- string
- uuid
- pathlib

### Custom Package
The custom_modules package contains:
- __init__.py
- file_utils.py
- math_tools.py

### How to Run
Open the project folder in VS Code.

Run the following command in Terminal:

python3 main.py

### Concepts Covered
- Importing modules
- Creating custom modules
- Creating packages
- Using __init__.py
- Using dir()
- Using if __name__ == "__main__"
- Functions and loops
- File handling

### Conclusion
This project demonstrates how Python modules
and packages help organize reusable code.
